# FurFinder capstone demo

A separate browser-only adaptation of Shawn Miranda’s defended PHP/MySQL capstone. Original source files in XAMPP remain unchanged.

All pet illustrations are original code-generated SVG assets. All records are fictional. No original uploads, identity documents, database credentials, PHP source, payment codes or applicant records are included. State exists only in page memory and resets on refresh or Reset demo. No login or backend is connected.

Supported: name/breed/type search; sample adoption questionnaire; lost reports; sample donation totals; admin application status updates; pet add/edit/remove; report and shelter status updates; descriptive analytics derived from sample data. No real applications or donations are sent.

The original capstone’s navy/gold styling is retained. The hero retains the original public Unsplash image URL. The demo does not claim shelter affiliations, current adoption fees or legal requirements.
