About FurFinder

FurFinder explores how a web application can connect adoptable animals with families, support lost-pet reporting, and help shelter administrators manage applications.

This interactive showcase adapts Shawn Miranda’s defended capstone, originally built with PHP and MySQL. All records here are fictional. Nothing is submitted to a shelter, and no donations are collected.

How does an application work?

Choose a sample pet, open its application, and use the prefilled fictional details. Then visit Admin preview to review the application and change its status.

Are these pets actually available?

No. Names, illustrations, reports, shelters, and application details are sample content for this portfolio demo.

Where is my information saved?

Demo changes stay in this page’s memory. Refreshing or resetting restores the starting examples. Use fictional details when trying the forms.

Can I make a real donation?

No. The donation screen demonstrates an amount selection and a progress update. It has no payment processor or payment QR code.
