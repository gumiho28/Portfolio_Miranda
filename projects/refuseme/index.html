RefuseMe

A gamified plastic-refusal companion for CAR youth. Click through the frame — bottom nav, cards, and buttons are all live.

Screen flow

Design notes

🟫 Pine / rust / gold palette pulls from Cordillera weaving instead of default "eco-app" green-on-white.
◆ The diamond "weave" stripe is the signature motif — used as a divider, never as decoration alone.
👆 Home → Log a Refusal is 2 taps. Home → Coach and Home → Community are 1 tap each.
🔢 Community counter and points animate on load to feel alive, per the brief.
Simulated data throughout — no backend, AI, or payments wired up, matching the prototype's out-of-scope list.
Built as an HTML wireframe standing in for the Figma file requested in the brief.
